# Ecommerce-Dashboard-Project
# 🛍️ E-commerce Power BI Dashboard

This project features a modern, interactive Power BI dashboard for an e-commerce business. It provides insights into sales, customer behavior, product performance, and inventory, supporting data-driven decision-making.

## 📊 Dashboard Features

- **Sales Analysis** → Daily, weekly, and monthly revenue trends
- **Top Products** → Best sellers by revenue and units sold
- **Conversion Funnel** → From visitors to completed purchases
- **Customer Segments** → New vs. returning, by geography or demographics
- **Inventory Overview** → Stock levels and low-stock alerts
- **Geographic Sales** → Map visual showing sales by region


## 🧰 How to Use

1. Clone or download this repository.
2. Open `EcommerceDashboard.pbix` in **Power BI Desktop**.
3. Connect to your own data or use the provided `sample-data.xlsx`.
4. Explore slicers, charts, and visuals.
5. Customize themes, visuals, and KPIs as needed.
